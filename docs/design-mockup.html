Graph Explorer: design mockup

Static mockup for the frontend of the graph analysis platform. Screen 1 is the main view: a graph is selected, the route query start=public through=vulnerable end=sink is applied, the matching subgraph is highlighted on the full graph, and one node is open in the details panel. Below it: tokens, components and every application state. Colors are design tokens (CSS variables), meant to become the Tailwind / shadcn theme.
